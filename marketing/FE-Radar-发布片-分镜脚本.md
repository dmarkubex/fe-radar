# FE-Radar · 远东产业情报雷达

## 90 秒产品发布片 — 分镜脚本 v1.0

> 风格基调：Apple 产品发布片。极致留白 · 黑场为底 · 单一金色信号为主角 · 文字即主视觉 · 旁白克制低沉 · 音乐由静到爆再收。
> 叙事主线：**从噪音到信号（From Noise to Signal）**，由两条产品哲学驱动——「信源比信息重要」「能用脚本就别用 Agent」。
> 语言：中文旁白 + 英文关键词点缀。
> 时长：90 秒（30fps = 2700 帧；60fps = 5400 帧）。

## 二、逐镜分镜脚本

> 每镜含：**画面 / 屏幕文字 / 旁白(VO) / 音乐音效(SFX) / 运动转场(Motion) / Remotion 实现提示**。
> 旁白节奏按中文约 **4–5 字/秒** 计，已与镜头时长对齐。

---

### SCENE 00 — 冷开场 · 噪音 ｜ 0:00–0:08（0–240f）

**画面**　纯黑底。无数灰色的新闻碎片——标题、数字、招标公告、价格曲线——从四面八方涌入，快速堆叠、重叠、轻微抖动，最终糊成一面混乱的灰色"噪点墙"。没有焦点，令人窒息。

**屏幕文字**（在碎片中一闪而过，灰色、不停滚动）
`政策 · 招标 · 扩产 · 检修 · 涨价 · 中标 · 事故 · 停产 · 并购 · 限电 …`

**旁白 VO**

> "每一天，这个行业，产生成千上万条消息。"

**SFX**　低频白噪音渐起，信息流的"沙沙"叠加声逐渐压迫；无旋律。

**Motion**　粒子系统持续涌入，碎片 opacity 0.25–0.6、随机旋转 ±8°、轻微视差抖动。

**Remotion 提示**　`Array.from({length:120})` 生成碎片，每片用 `interpolate(frame, [delay, delay+20],[0,1])` 错峰入场；位置用种子随机；抖动叠加 `@remotion/noise` 的 `noise2D` 做微位移。

---

### SCENE 01 — 张力 · 代价 ｜ 0:08–0:14（240–420f）

**画面**　噪点墙继续翻涌。镜头中，一张**红色的重要消息卡片**短暂浮出、闪烁一下，瞬间又被灰色碎片吞没、淹没消失。

**屏幕文字**
`你真正需要的，也许只有 3 条。`

**旁白 VO**

> "但真正重要的，可能只有三条。错过一条，也许就是一个项目、一次涨价、一场风险。"

**SFX**　心跳般低鼓点 ×2；句末骤然抽走环境声，留一瞬空。

**Motion**　红卡 `scale` 0.9→1.0 弹入后被灰片覆盖 `opacity→0`。

**Remotion 提示**　红卡用 `spring()` 入场；覆盖用后续碎片 z-index 抬升 + 红卡 `opacity` 下降同步。

---

### SCENE 02 — 转折 · 留白 ｜ 0:14–0:18（420–540f）

**画面**　"啪"——所有灰色碎片骤然被抽离，全部向画面正中心坍缩成一个亮点，随即熄灭。屏幕归于**纯黑**。极致留白，几乎让人屏息。

**屏幕文字**　无。

**旁白 VO**　（静默）

**SFX**　真空"吸气"感 + 一记深沉 **bass hit**（揭示前的心跳）。

**Motion**　全部粒子 `interpolate` 向中心点收缩（collapse），最后 6 帧统一 `opacity→0`。

**Remotion 提示**　复用 SCENE 00 的粒子数组，把目标坐标统一设为中心 `[960,540]`，用 `spring({config:{damping:200}})` 收束；这是 Apple 经典的"清空—再揭示"。

---

### SCENE 03 — 揭示 · 雷达亮起 ｜ 0:18–0:26（540–780f）

**画面**　黑场中央，一圈细腻的**雷达扫描光环**缓缓亮起、旋转一周；扫描线扫过之处，**三个金色信号点**依次被点亮。光环中心，浮现产品标识。

**屏幕文字**
`FE-Radar`
`远东 · 产业情报雷达`

**旁白 VO**

> "这，就是 FE-Radar。远东，产业情报雷达。"

**SFX**　清澈合成器上扬音，主题旋律第一声落下；扫描"嗡"声。

**Motion**　扫描线 0→360° 一周；信号点 staggered glow；Logo `scale` 0.96→1.0 + 微辉光。

**Remotion 提示**　扫描线用 `conic-gradient` + `rotate(frame…)` + 圆形 `mask`；信号点 `spring` 缩放 + CSS `filter: drop-shadow` 金色辉光。

---

### SCENE 04 — 第一信条 · 信源比信息重要 ｜ 0:26–0:40（780–1200f）

**画面**　雷达环平滑展开为一组**同心圆信源图**：最外圈是密集的信源节点，经过"分级"动画，向内沉淀为清晰的三层 **T1 / T2 / T3**；右侧浮现**关注圈 C1 / C2 / C3**。整体冷静、有序。

**屏幕文字**
`第一信条 — Signal over Noise`
`信源，比信息更重要`
`T1 权威源 · T2 行业源 · T3 补充源`

**旁白 VO**

> "我们相信，信源，比信息更重要。先精选最值得信任的源头，再处理信息。国家能源局、发改委、工信部……每一条信号，都能追溯到它的出处。"

**SFX**　旋律铺底；清脆 UI"点选"声 ×3，对应三层归位。

**Motion**　外圈节点向内归位分层；T1/T2/T3 标签依次淡入。

**Remotion 提示**　节点用极坐标布局（`r·cos/ sin`）；分层用 `spring` 让节点半径从大到小落位；标签 `Sequence` 错峰。

---

### SCENE 05 — 第二信条 · 能用脚本就别用 Agent ｜ 0:40–0:52（1200–1560f）

**画面**　画面转为一条**精密流水线**：规则、阈值、聚类以冷静的"代码块/齿轮"形态运转；只有标着"语言"的少数节点会亮起暖光（代表 LLM）。像一台克制、可靠的精密机械，没有任何花哨。

**屏幕文字**
`第二信条 — Discipline by Design`
`能用代码，绝不交给猜测`
`规则 × 阈值 × 聚类 ⟶ 确定性`

**旁白 VO**

> "我们也相信，克制。能用代码解决的，绝不交给猜测。规则、阈值、聚类，由代码精确掌控；AI，只做它最擅长的——语言。"

**SFX**　精准的机械"咬合"节拍；节奏开始收紧。

**Motion**　数据块沿管线推进，节点依次点亮；"语言"节点亮暖金，其余保持冷白。

**Remotion 提示**　管线用一条 `path`，数据块沿 `getPointAtLength` 运动；点亮用 `interpolate` 控 `opacity/glow`，冷白 `#E6E8EC` vs 暖金 `#F5C97B`。

---

### SCENE 06 — 引擎 · 每 6 小时自动运转 ｜ 0:52–1:02（1560–1860f）

**画面**　8 阶段 pipeline 高速演示：**抓取 → 过滤 → 五维评分 → 聚类 → 告警**。数据如一道**光流**穿过管线，速度感强烈。背景一枚时钟轻转，强调"每 6 小时"。

**屏幕文字**
`每 6 小时 · 自动 — Every 6 hours. Automatically.`
`抓取 → 过滤 → 5 维评分 → 聚类 → 告警`

**旁白 VO**

> "每六小时，它自动醒来一次。抓取、过滤、五维评分、聚类、告警——一气呵成。"

**SFX**　节奏明显加快，能量层叠加，向高潮蓄力。

**Motion**　光流贯穿，关键词随光流到达依次"点亮"；时钟指针快转一圈。

**Remotion 提示**　光流用渐变线段沿管线移动 + 拖尾 `blur`；阶段词用 `staggerDelay` 数组逐个 `spring` 入场。

---

### SCENE 07 — 零漏报 ｜ 1:02–1:10（1860–2040f）

**画面**　镜头推近雷达上的**"远东自己"节点**。该节点的评分由代码计算（D2_chain），始终高亮、强脉冲，周围相关连线被逐一点亮——**永不遗漏**。

**屏幕文字**
`关于"自己"，零漏报`
`Zero blind spots · 代码级保障`

**旁白 VO**

> "尤其是，关于远东自己的每一条动态——由代码确保，零漏报。"

**SFX**　一记笃定低音；锁定感"叮"。

**Motion**　自家节点 `scale` 脉冲（呼吸光晕）；相关连线 `path` 逐条 draw-in。

**Remotion 提示**　脉冲用 `Math.sin(frame/φ)` 驱动 `scale/opacity`；连线用 `strokeDasharray` + `strokeDashoffset` 实现描线。

### SCENE 08 — 能力 · 三种呈现 ｜ 1:10–1:20（2040–2340f）

**画面**　三块产品界面优雅滑入（Apple 式 UI 展示，带轻微 3D 视差倾斜）：
① **时间线 Timeline** ② **每日精选 Briefing** ③ **智能日报 Daily / 大宗商品行情简报**。

**屏幕文字**
`时间线 Timeline · 精选 Briefing · 日报 Daily`
`铜 · 锂 行情简报 — 每个工作日 16:00`

**旁白 VO**

> "它把混乱，整理成三种样子：连续的时间线，每日的精选，和一份替你读完一切的日报。甚至，每天下午四点，一份铜与锂的行情简报。"

**SFX**　高潮前的旋律抬升；UI 滑入"唰唰"轻响。

**Motion**　三屏 staggered slide-in + parallax 视差；轻微悬浮。

**Remotion 提示**　每屏一个 `Sequence`，`translateY/translateX + perspective(1200px) rotateY(8deg)`；用真实截图或高保真 mock 图层提升质感。

### SCENE 09 — 高潮 · 从噪音到信号 ｜ 1:20–1:26（2340–2520f）

**画面**　镜头拉远，**开场那面灰色噪音墙重现**——雷达光环猛地一扫，灰色碎片瞬间收敛、凝聚成几条**清晰、金色的信号线**。噪音 → 信号，视觉闭环回扣开场。

**屏幕文字**
`从噪音，到信号。`
`From Noise to Signal.`

**旁白 VO**

> "从噪音，到信号。让每一个决定，都有依据。"

**SFX**　主题旋律最强音 + 上扬泛音；情绪到顶。

**Motion**　全屏灰粒子被一道扫描线"吸附"成数条金色信号线。

**Remotion 提示**　复用 SCENE 00 粒子，目标位置改为几条直线上的采样点；扫描线经过即触发该列粒子变金、归位。

## 三、制作规格

**画幅 / 帧率**　1920×1080（16:9）主版；建议另出 1080×1920 竖版用于钉钉/手机。基准 **30fps**（文件小、够顺）；追求高级质感可上 **60fps**。

**色板（克制，单一金色为主角）**

| 用途                  | 色值                          |
| --------------------- | ----------------------------- |
| 背景近黑              | `#0A0B0D`                     |
| 信号金（主角/强调）   | `#F5C97B` → `#E8B65A`（渐变） |
| 噪音灰（中性碎片）    | `#6B7280` / `#3A3D42`         |
| 风险红（仅 SCENE 01） | `#E5484D`                     |
| 主文字白              | `#F5F6F7`                     |

> 全片**只用一个强调色（金）**，是 Apple 式高级感的关键——其余皆黑白灰。

**字体**　中文：苹方 / 思源黑体（Source Han Sans）；英文：SF Pro Display / Inter。大字重对比：标题 Semibold/Bold，副文 Regular，字间距略放大。

**配乐方向**（用情绪描述，避免侵权，建议买正版授权或 AI 生成）
环境噪点 → 极简脉冲 → 渐强合成器 → 揭示明亮音 → 高潮最强音 → 收束余韵。参考"干净电子 + 电影感"的科技发布片基调（**不要**直接套用任何品牌的原声）。

**旁白配音**　男声或女声皆可，要求：**低、稳、慢、有停顿**，不煽情。每句之间留半拍。

**资产清单**　Logo（SVG，含单色版）/ 三屏产品界面截图或高保真 mock / 信源 logo 占位（可马赛克化避免侵权）/ 字体文件 / 配乐 + 旁白音轨。

## 四、Remotion 工程落地指引

**推荐结构**

```
src/
  Root.tsx                 // registerRoot + Composition (1920x1080, fps=30, durationInFrames=2700)
  FeRadarFilm.tsx          // 主时间轴：用 <Series> 串联 10 个场景
  scenes/
    S00_Noise.tsx
    S01_Cost.tsx
    S02_Collapse.tsx
    S03_Reveal.tsx
    S04_Sources.tsx
    S05_Discipline.tsx
    S06_Engine.tsx
    S07_ZeroMiss.tsx
    S08_Capabilities.tsx
    S09_NoiseToSignal.tsx
    S10_Signoff.tsx
  components/ RadarSweep.tsx · ParticleField.tsx · Pipeline.tsx · UIPanel.tsx
  audio/ music.mp3 · vo.mp3
```

**核心 API**　`useCurrentFrame()` 驱动一切；`interpolate()` 做线性映射；`spring()` 做自然弹入；`<Series>`/`<Sequence>` 排时间轴；`<Audio>` 贴配乐与旁白（用 `startFrom` 对齐时间码）；粒子抖动用 `@remotion/noise`；转场可用 `@remotion/transitions`。

**依赖**　`remotion` `@remotion/cli` `@remotion/transitions` `@remotion/noise`。

**预览 / 渲染**

```bash
npx create-video@latest          # 初始化（选 Blank/Hello World 模板）
npm run start                    # 打开 Remotion Studio 实时预览
npx remotion render FeRadarFilm out/fe-radar.mp4 --codec=h264
# 竖版：再建一个 1080x1920 的 Composition 复用场景组件
```

> 时间码对齐技巧：把"二、逐镜脚本"里每镜的起始帧（如 SCENE 04 = 780f）直接作为 `<Series.Sequence durationInFrames=…>` 的累加边界，VO 音轨用同一组帧号 `startFrom` 切片，画面与旁白天然同步。

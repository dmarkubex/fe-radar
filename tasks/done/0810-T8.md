# T8 — Dockerfile 换源顺序反了，首次 apt 安装始终走 deb.debian.org

- executor: `grok`

## ⚠ 本任务禁止 git 提交

不要 `git commit` / `add` / `stash` / `reset` / `checkout <文件>`。改动留工作区。
进度**追加**到 `handoff.md` 末尾。跑命令用 `2>&1`。
**不要尝试 `docker build`**——本机 docker 守护进程不可用（构建在 Windows 构建机上做）。

## 已观测问题（主会话实测）

三个 Dockerfile 里都是同一个模式：

```dockerfile
RUN apt-get update && \
    apt-get install -y ... && \      ← 安装在前，走默认 deb.debian.org
    sed -i -e "s#deb.debian.org#${DEBIAN_MIRROR}#g" ...   ← 换源在后
```

**换源发生在安装之后，所以该 RUN 块内的安装完全没用上阿里云镜像**，
只有同阶段后续的 apt 调用才受益。

**实测证据**：在 Windows 构建机上跑
`docker run --rm node:22-slim sh -c "apt-get update && apt-get install -y ca-certificates python3 make g++"`
——**两个容器分别跑了 2 分钟和 7 分钟仍未完成**。内网访问 deb.debian.org 极慢。

此前一直没暴露，是因为那些层被 Docker 缓存了。T4 刚改动了
`Dockerfile.worker:41-42`（deps 阶段首次安装，新增 python3/make/g++），
**缓存必然失效 → 下次构建会真去 deb.debian.org 拉包 → 大概率超时或极慢**。

## 要做的事

把每个 `RUN` 块里的 `sed` 换源**移到 `apt-get update` 之前**，使该块的安装即走镜像源。

涉及位置（主会话已定位，请逐个核对行号可能因编辑而偏移）：

| 文件                                  | RUN 块                       |
| ------------------------------------- | ---------------------------- |
| `deploy/Dockerfile.worker`            | 41-47、134-139、140-159 三处 |
| `deploy/Dockerfile.web`               | 78-80、86-87、112 附近       |
| `deploy/Dockerfile.postgres-zhparser` | 12-16、20-21                 |

注意事项：

1. **`sed` 依赖的 `${DEBIAN_MIRROR}` / `${DEBIAN_SECURITY_MIRROR}` 必须在该阶段有 ARG 声明**。
   多阶段构建里 ARG 不跨阶段继承——移动后确认每个用到它的阶段都声明了这两个 ARG，
   没有就补 `ARG DEBIAN_MIRROR` / `ARG DEBIAN_SECURITY_MIRROR`（带原默认值）。
2. `sed` 里已有 `2>/dev/null || true` 容错，移动后保留——
   某些基础镜像没有 `/etc/apt/sources.list.d/*`，不容错会整块失败。
3. **Debian 12+ 用的是 `/etc/apt/sources.list.d/debian.sources`（DEB822 格式），
   不是传统的 `sources.list`。** 请确认现有 `sed` 表达式对本项目 base 镜像
   （`node:22-slim`）实际生效——若不生效，安装仍会走官方源，改了顺序也没用。
   **这一条必须实际验证**：读一下 node:22-slim 里 apt 源文件的实际路径与格式
   （可用 `grep` 现有 Dockerfile 的写法 + 查 Debian 版本推断），把结论写进 handoff.md。
   不确定就在 handoff.md 说明，不要假装验证过。
4. **不要**顺手改镜像地址本身、不要改安装的包列表、不要动多阶段结构。

## 机械检查（结果写进 handoff.md）

```bash
# 每个 RUN 块内，sed 是否都排在 apt-get update 之前
for f in deploy/Dockerfile.worker deploy/Dockerfile.web deploy/Dockerfile.postgres-zhparser; do
  echo "== $f"
  awk '/apt-get update/{print NR": [update]"} /apt-get install/{print NR": [install]"} /sed -i/{print NR": [sed]"}' "$f"
done
# 用到 DEBIAN_MIRROR 的阶段是否都声明了 ARG
grep -n "ARG DEBIAN_MIRROR\|ARG DEBIAN_SECURITY_MIRROR\|DEBIAN_MIRROR\|FROM " deploy/Dockerfile.worker
```

输出必须显示：每个块内 `[sed]` 行号 < `[update]` 行号。

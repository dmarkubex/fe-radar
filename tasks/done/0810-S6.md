## 已观测缺陷（必须回代验算）

`apps/web/instrumentation.ts:38` 的门控：

```ts
if (process.env.NEXT_PHASE === "phase-production-server" && process.env.NODE_ENV === "production") {
```

**该条件运行时永不为真。** 主会话在 Next.js 15.5.18 全量搜索 `node_modules/next/dist`：

```

```

部署文件也从未设置它（`grep -rn NEXT_PHASE deploy/ apps/web/package.json` 零命中）。
即整段启动校验是死代码，T-SEC-16 名义上的启动期校验实际不存在。

**测试为何全绿**：`apps/web/__tests__/instrumentation.test.ts` 三处
`vi.stubEnv("NEXT_PHASE", "phase-production-server")` 人为注入该变量。这是假绿。

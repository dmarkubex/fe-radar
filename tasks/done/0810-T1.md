## 已观测失败（可直接复现）

```bash
cd /Volumes/SD/AI-Timeline-web
env -u NEXTAUTH_URL -u AUTH_URL NODE_ENV=production npx --prefix apps/web next build apps/web
```

输出：

```
Failed to compile.
./app/api/admin/project-codes/__tests__/route.test.ts
13:3  Error: 'updateWhere' is assigned a value but never used.
      Allowed unused vars must match /^_/u.  @typescript-eslint/no-unused-vars
15:3  Error: 'selectFrom' is assigned a value but never used.
      Allowed unused vars must match /^_/u.  @typescript-eslint/no-unused-vars
```

**生产镜像构建因此直接失败，整条发布路径阻断。**
此前所有验收只跑 `vitest` + `tsc`，两者都不会报这个错。

## 要做的事

修掉这两个未使用变量。**优先判断它们是否本就该被使用**——
`updateWhere` / `selectFrom` 是 mock 链的一部分，若测试本意是断言更新/查询行为却漏了断言，
那么正确修法是**补上断言**而不是加下划线前缀。先读懂该测试想验证什么。

若确认它们确实无用，再按 ESLint 规则重命名为 `_updateWhere` / `_selectFrom` 或删除。
**两种处置都要在 handoff.md 说明理由。**

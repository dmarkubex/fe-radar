# A-9（Medium）— MinIO runbook 建桶步骤不幂等

`docs/runbook/minio-least-privilege.md:36` 附近的 `mc mb` 命令在 bucket 已存在时会报错。

**失败场景**：生产两个 bucket 已存在（当前就是如此）→ 照抄步骤执行 →
`mc mb` 非零退出 → 在 `set -e` 或自动化脚本中直接中断，
**后续的 `policy create` / `attach` 全部没跑到，收权流程无法完成，旧 root 凭据只能继续用**。

修法：两条建桶命令加 `--ignore-existing`（MinIO 官方提供的既有桶无错退出参数）。

参考（`mc mb` 官方语义）：

```bash
mc mb --ignore-existing <ALIAS>/<BUCKET>
# --ignore-existing: 目标已存在时不报错、退出码 0
```

顺便检查该 runbook 里**其余步骤是否同样不幂等**（例如 `mc admin user add` 在用户已存在时、
`mc admin policy create` 在 policy 已存在时的行为），把发现写进 handoff.md。
运维 runbook 的价值在于可以重复执行——中途失败后能从头再来，而不是需要人工判断跑到哪一步了。

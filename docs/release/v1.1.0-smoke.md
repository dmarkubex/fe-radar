## Fixture 注入（v11-smoke-prep.ts）

```bash
# 注入所有 4 个场景
pnpm tsx scripts/v11-smoke-prep.ts --all

# 或分别注入
pnpm tsx scripts/v11-smoke-prep.ts --scenario holiday
pnpm tsx scripts/v11-smoke-prep.ts --scenario degraded
pnpm tsx scripts/v11-smoke-prep.ts --scenario push-retry
pnpm tsx scripts/v11-smoke-prep.ts --scenario template-lint
```

脚本幂等（重复执行不报错）。各场景说明：

| --scenario | 操作 |
|---|---|
| `holiday` | 将今日插入 `briefing_holidays`；删除今日 `commodity_briefings` 行（如有）|
| `degraded` | 插入今日 `commodity_briefings`（`gen_status='degraded'`）|
| `push-retry` | 为最新 briefing 插入一条 `briefing_pushes`（`push_status='failed'`, `attempt_count=3`）|
| `template-lint` | 插入一条 `commodity_briefings`（`gen_status='failed'`, `gen_error` 含 `TEMPLATE_LINT_MISSING_PLACEHOLDER`）|

## 失败排查

### 节假日跳过测试失败

- 检查 `briefing_holidays` 表是否包含今日行：
  ```sql
  SELECT * FROM briefing_holidays WHERE holiday_date = CURRENT_DATE;
  ```
- 若行不存在，重新执行 `pnpm tsx scripts/v11-smoke-prep.ts --scenario holiday`。
- 检查 `commodity_briefings` 是否有今日残留行（`gen_status != 'skipped'`），手动删除：
  ```sql
  DELETE FROM commodity_briefings WHERE briefing_date = CURRENT_DATE;
  ```

### 字段缺失降级测试失败

- 检查 fixture 行是否存在：
  ```sql
  SELECT id, gen_status FROM commodity_briefings WHERE gen_status = 'degraded' ORDER BY id DESC LIMIT 5;
  ```
- 若不存在，重新执行 `--scenario degraded`。

### 推送失败重试测试失败

- 检查 `briefing_pushes` 表：
  ```sql
  SELECT bp.*, bt.name FROM briefing_pushes bp
  JOIN briefing_targets bt ON bt.id = bp.target_id
  WHERE bp.push_status = 'failed' AND bp.attempt_count = 3
  ORDER BY bp.id DESC LIMIT 5;
  ```
- 若 `briefing_targets` 表为空，先 seed 一条 target，再执行 `--scenario push-retry`。

### 模板 lint 失败测试失败

- 检查 fixture 行：
  ```sql
  SELECT id, gen_status, gen_error FROM commodity_briefings
  WHERE gen_status = 'failed' ORDER BY id DESC LIMIT 5;
  ```
- 确认 `gen_error` 含字符串 `TEMPLATE_LINT_MISSING_PLACEHOLDER`。

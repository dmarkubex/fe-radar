# 非上市 C2 司法数据：商业 API 评估（P3）

评估日期：2026-06-17  
场景：FE-Radar 已覆盖 **A 股上市主体** 涉诉公告（巨潮/深交所 + `legal` 告警）；**非上市 C2**（如江南电缆）无法定交易所披露，需第三方数据源。

## 1. 覆盖缺口

| 主体类型       | 当前 FE-Radar 能力                       | 缺口                       |
| -------------- | ---------------------------------------- | -------------------------- |
| C1/C2 上市公司 | 巨潮 `searchkey` + 按 `stockCode` 分批源 | 未达披露标准的中小诉讼     |
| 非上市 C2      | 无                                       | 裁判文书、开庭、执行、失信 |
| 非上市供应商   | 无                                       | 被执行、失信、破产         |

## 2. 主流商业方案对比

| 供应商              | 典型能力                             | 接入方式       | 粗估成本（500 人内网）                | 合规要点                                       |
| ------------------- | ------------------------------------ | -------------- | ------------------------------------- | ---------------------------------------------- |
| **企查查 Open API** | 企业司法风险、裁判文书摘要、开庭公告 | REST + API Key | 按次/包年，司法模块通常 ¥3–8 万/年 起 | 合同授权范围、禁止二次售卖、日志留存           |
| **天眼查 Open API** | 同上 + 关系图谱                      | REST           | 与企查查同级                          | 同上                                           |
| **启信宝 / 百融**   | 批量核查、供应商准入                 | REST / 离线包  | 按查询量                              | 适合采购准入批量跑，非实时雷达                 |
| **裁判文书网直连**  | 全量文书                             | 无官方 API     | 自建爬虫维护成本高                    | **不推荐**（见可行性分析：登录/加密/政策收紧） |

## 3. 与 FE-Radar 架构的集成建议

若采购商业 API，建议 **独立 `fetcher_type=court-api` adapter**（Full Mode），而非混入 news pipeline：

```
court-api job（日级 / 周级）
  → 按 entities(C2, meta.stockCode 为空) 批量查询
  → 仅入库 title + 案号 + 法院 + 日期 + 深链（不存全文）
  → scrubber 前置（当事人姓名脱敏后再进 LLM）
  → alert_type=legal（已有）
```

**硬约束对齐**：

- 公网 LLM 前必经 `scrubber`；司法全文 PII 密度高，建议 **仅摘要字段** 进评分
- 不存原始 HTML/PDF（FR-12 延伸：司法 PDF 同理）
- 代理池不用于绕过 robots；商业 API 走合同通道，无 robots 问题
- 90 天内容保留策略适用于 items 元数据

## 4. 成本—收益建议

| 选项                  | 适用                        | 建议                                                      |
| --------------------- | --------------------------- | --------------------------------------------------------- |
| **暂不采购**          | 竞品监控以上市主体为主      | **默认**：江南电缆等非上市 C2 接受媒体二手 + 人工补充     |
| **采购企查查/天眼查** | 采购 / 法务需供应商司法核查 | 独立 milestone；预算 ¥3–8 万/年；日更批量 ≤ C2 名单 50 家 |
| **执行信息公开网**    | 信用风险（被执行/失信）     | 技术可行但 PII 高；仅建议做法务专项，不进主 timeline      |

## 5. 决策记录（待 Human）

1. 非上市 C2 是否纳入 v1.2 范围？若否，维持现状。
2. 若采购，优先 **司法风险变更推送** 还是 **全量历史回填**？（推送模式更省配额）
3. 数据使用范围是否仅限内网 500 人？需在供应商合同中明确。

## 6. 结论

- **上市 C2 竞品涉诉**：已通过交易所公告通道 + `legal` 告警满足，无需商业 API。
- **非上市 C2**：商业 API 是唯一可规模化方案；建议 **按需采购**，不作为 v1.1 阻塞项。
- **裁判文书网爬虫**：无论是否采购商业 API，均不建议作为 FE-Radar 信源。

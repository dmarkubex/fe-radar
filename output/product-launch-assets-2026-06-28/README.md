# FE-Radar Product Launch Assets

Created: 2026-06-28

This package prepares reusable assets and a launch video script for FE-Radar.

## Contents

- `brand/brand-guidelines.md` - brand position, colors, slogans, typography, design warnings
- `brand/brand-palette.png` - color swatch
- `brand/fareast-logo-transparent.png` - transparent color logo
- `brand/fareast-logo-white.png` - white logo for dark scenes
- `brand/fareast-symbol-transparent.png` - compact symbol
- `existing/high-res-originals.md` - found high-resolution assets and recommended usage
- `existing/ui/` - copied FE-Radar UI originals
- `existing/video-frames/` - copied historical video frames
- `prompts/business-context-image-prompts.md` - generation prompts for support visuals
- `generated/` - generated business context images
- `script/product-launch-video-script.md` - 80-90s launch video script
- `qc/existing-assets-contact-sheet.jpg` - visual index of existing assets
- `qc/generated-assets-contact-sheet.jpg` - visual index of generated context images
- `qc/verification.md` - local verification notes
- `asset-manifest.json` - file inventory with dimensions and short hashes

## Direction

This asset package intentionally moves away from the earlier style-level starfield montage. The new direction is:

- real FE-Radar UI as proof
- Far East blue and cyan brand palette
- industry intelligence context
- large readable product panels
- source-first and rules-first messaging

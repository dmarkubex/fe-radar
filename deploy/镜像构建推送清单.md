# 镜像构建推送清单

> 适用位置：在构建服务器的项目根目录执行，例如 `/Volumes/SD/AI-Timeline-web`。
> 本清单只构建并推送 FE-Radar 自建镜像；公共镜像不推 Harbor。

## 1. 登录 Harbor

```bash
docker login harborssl.fegroup.cn
```

## 2. 设置镜像仓库变量

这行可以单独执行。后续命令必须在同一个 shell 窗口里继续执行，`$R` 才会生效。

```bash
R=harborssl.fegroup.cn/custom-project
echo "$R"
```

`echo "$R"` 应输出：

```bash
harborssl.fegroup.cn/custom-project
```

## 3. 构建自建镜像

```bash
docker build -f deploy/Dockerfile.postgres-zhparser -t "$R/fe-radar/postgres-zhparser:pg16" .
docker build -f deploy/Dockerfile.worker            -t "$R/fe-radar-worker:latest" .
docker build -f deploy/Dockerfile.migrate           -t "$R/fe-radar-migrate:latest" .
docker build -f deploy/Dockerfile.web               -t "$R/fe-radar-web:latest" .
docker build -f deploy/Dockerfile.backup            -t "$R/fe-radar-backup:latest" .
```

## 4. 推送自建镜像

```bash
docker push "$R/fe-radar/postgres-zhparser:pg16"
docker push "$R/fe-radar-worker:latest"
docker push "$R/fe-radar-migrate:latest"
docker push "$R/fe-radar-web:latest"
docker push "$R/fe-radar-backup:latest"
```

## 5. 对应服务

| 镜像                              | 用途                              |
| --------------------------------- | --------------------------------- |
| `fe-radar/postgres-zhparser:pg16` | Postgres 16 + pgvector + zhparser |
| `fe-radar-worker:latest`          | worker + scheduler 共用镜像       |
| `fe-radar-migrate:latest`         | 一次性 migration / seed 镜像      |
| `fe-radar-web:latest`             | Next.js web / API                 |
| `fe-radar-backup:latest`          | MinIO backup / provisioning       |

## 6. 不需要推送的公共镜像

这些镜像由部署服务器直接拉取，不在本清单中推送到 Harbor：

```text
redis:7-alpine
minio/minio:RELEASE.2025-09-07T16-13-09Z
grafana/grafana:12.1.1
diygod/rsshub@sha256:0d40e1c9e5c3811da2c4eeaf7443e1bcdc6d7dc5510aa3df98bab0f979c03059
```

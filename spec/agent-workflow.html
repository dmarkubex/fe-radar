7并行安全保障 为什么 8 个 agent 同时跑不会撞车

  • 每个 task 的 scope 严格 ≤ 1 个 agent；多 agent 协作的功能拆为 a/b 子 task（如 T-M4-05a + T-M4-05）
  • 跨 agent 接口先由 agent-core / packages/shared 定义类型，再各自实现
  • 同一 milestone 内同一文件的修改禁止两个 task 并发；CI 用 git diff --name-only 校验 PR 间 file 重叠
  • packages/core 不依赖 packages/db，业务规则纯函数化便于单测和并行开发
  • apps/web 与 apps/worker 不互相 import；CI madge --circular 检查循环依赖
  • 关键串行点（critical path）用紫色发光标识：T-M0-01 → T-M0-02 → T-M1-10 → T-M2-14 → T-M2-15 → T-M4-05a → T-M5-08
